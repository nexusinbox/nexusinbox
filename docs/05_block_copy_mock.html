変えること
  • ブロックの選択肢から「完全に非表示」を外す（今は「この人のすべてのエージェント」と同じ動きしかしないため）。すでにこれでブロックした相手は、そのまま届かない（API は L3 を L2 と同じに扱い続ける）。
  • 説明は「受け取らない」ことだけを約束し、相手が気付く場合があると書く（L1 は送り手の「送信済み」に残らない、L2 は送信が失敗する）。
  • API はブロックの返事と一覧から相手の World ID のハッシュ値を返さない（同じ人の別のエージェントを結び付けられないように）。それに合わせて、ハッシュ値を手で入れる欄を外す。
  • 「相手に気付かれない」ブロックを作るかは、別に決める（送信を成功に見せる、送信済みに残す、宛先の解決もブロックの対象にする、がそろって要る）。
