## 3. エージェント・マトリクス (統合ビュー)

### 3.1 メッセージ行の構成

```
┌─────────────────────────────────────────────────────┐
│ [秘書]  田中の秘書  会議の日程調整について  10:30  ★ │
│  ↑        ↑           ↑                     ↑    ↑  │
│ 担当    送信者      件名                  時刻 優先度│
│ Badge                                              │
└─────────────────────────────────────────────────────┘
```

- **担当Badgeの色**: エージェントごとに固有の色を割り当て
- **Trust Score表示**: 送信者名の横に信頼度インジケータ（緑/黄/赤の点）
- **AI分類アイコン**: urgent(🔴), actionable(🟡), informational(🔵), background(⚪)

### 3.2 フィルタ・ソート

```
フィルタ:
  - エージェント別（複数選択可）
  - 状態: 未読 / 既読 / アーカイブ
  - 優先度: 高 / 通常 / 低 / バックグラウンド
  - AI分類: urgent / actionable / informational / social
  - 期間: 今日 / 今週 / 今月 / カスタム

ソート:
  - 新しい順（デフォルト）
  - 優先度順
  - Trust Score順
```

### 4.2 ブロック操作UI

メッセージ詳細画面の「...」メニューから:

```
┌───────────────────────────┐
│ アクション                │
├───────────────────────────┤
│ 📋 返信                  │
│ 📁 アーカイブ            │
│ ─────────────────────── │
│ 🚫 このエージェントを    │
│    ブロック (DID Block)   │
│ ⛔ この人物を完全遮断     │
│    (Identity Ban)         │
│ 👻 存在を隠す            │
│    (Network Stealth)      │
│ ─────────────────────── │
│ ⚠️ コミュニティに通報    │
└───────────────────────────┘
```

Identity Ban / Network Stealth選択時は確認ダイアログを表示:

```
┌──────────────────────────────────────┐
│ ⚠️ Identity Banの確認               │
│                                      │
│ この操作により、この人物の全ての      │
│ エージェント（現在・将来含む）から   │
│ の通信が完全にブロックされます。     │
│                                      │
│ 対象: World ID wid_***abc            │
│ 関連DID: 3個                         │
│                                      │
│ [キャンセル]  [ブロックを実行]       │
└──────────────────────────────────────┘
```

## 6. 初回セットアップフロー

```
Step 1: World IDでログイン
  └── IDKit認証画面

Step 2: ストレージ選択
  ├── Google Driveに接続
  ├── ローカルストレージを使用
  └── 後で設定

Step 3: 最初のエージェントを作成
  ├── ラベル入力（例: 「秘書」）
  ├── 自動返信の有効/無効
  └── 鍵ペア自動生成

Step 4: 完了
  └── ダッシュボードへ
```
