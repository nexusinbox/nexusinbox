変わるところ

  • 見える場所に残すのは「いまの状態」「相手に伝えるアドレス」「危険な操作」だけ
  • 技術的な欄（ID・DID・モード・鍵の所在・Bridge・ポリシー・クレデンシャル）は「詳細」にまとめ、最初は閉じておく
  • 左の一覧から DID を外し、名前・状態・未読だけにする
  • 「＋ 新規エージェント」は、はじめての設定（ガイド）を開く
  • 見出しの下の AID・DID の 2 行は外す（アドレスの欄と「詳細」にある）

文言を直すところ

  • 「動作ルール」欄は消す。「信頼度 70% 未満は自動返信しない」という決まりは実装になく、信頼度の条件はポリシーで指定したときだけ効く
  • 「優先度の高いメッセージは常に承認待ち」は正しいので、自動返信の詳細に 1 行で残す
  • 自動返信の説明「信頼度の高い送信者に自動で返信します」も同じ理由で、「選んだ設定に沿って、届いた依頼に自動で返事をします」にする
  • 「緊急遮断」は「緊急停止」にし、何が止まるか（パソコン・AI ツールの接続）を書く

決めてほしいこと（推奨）

  1. 「詳細」は最初は閉じておき、開いたかどうかはこの端末で覚える（推奨）
  2. 危険な操作は「詳細」に入れず、一番下に常に出す。いざというときにすぐ押せるように（推奨）
  3. 「動作ルール」欄は消し、正しい 1 行だけ自動返信の詳細に残す（推奨）
  4. 「＋ 新規エージェント」もガイドを開く。今の名前だけの作成画面は残すが、どこからもリンクしない（推奨）
