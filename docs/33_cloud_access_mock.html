変わるところ

  • 「いまの状態」に「クラウドの AI」の行を足す
  • オン・オフはこの画面だけで切り替える。ターミナルでの操作は要らない
  • URL は 1 台のパソコンに 1 つ。オフにしてまたオンにしても変わらない

しくみ（作るときのメモ）

  • オン・オフは API に保存する（パソコンごと、初期値はオフ）
  • パソコンのプログラムは、30 秒ごとの問い合わせでこの設定を受け取り、オンなら中継につなぐ。オフなら中継から抜ける
  • 「準備中」は、オンにしてから、パソコンが中継につながるまで（初回は証明書の取得も含む）。パソコンが中継につながったことを API に知らせたら「使えます」
  • 起動の仕組み（nexusinbox connect / start）は、中継と証明書の置き場所の指定を常に渡す。使うかどうかは上の設定で決まる
  • オフにした時点で入口が閉じるので、許可が残っていても届かない

決めてほしいこと

  1. オン・オフを画面から切り替える方式でよいか（パソコン側でコマンドを打つ方式より簡単。代わりに、Web にログインできる人がオンにできる）
  2. 「使うのをやめる」で、つながっている AI の許可もまとめて切るか（推奨: 切る。またオンにしたら、AI ごとに許可し直す）
  3. 行の名前は「クラウドの AI」でよいか
