● つながっています（このパソコン: macOS）

クラウドの AI からつなぐ

Muse など、インターネット上で動く AI に、この受信箱を読ませて下書きを作らせられます。送るのは、いつもあなたです。

https://k3x9q7.mcp.nexusinbox.ai/mcp
  1. AI のアプリで「カスタムコネクタ」(または「MCP サーバを追加」) を開き、この URL を貼る
  2. NexusInbox の許可の画面が開くので、内容を確かめて「許可する」
  3. AI に「受信箱を見て」「この返事を下書きして」と頼む。下書きは「確認が必要」に届く
AI を提供する会社（Muse なら Meta）は、AI に読ませたメッセージの本文を見ます。NexusInbox の運営は見ません。

このパソコンの NexusInbox が動いている間だけ使えます。

しくみ（段階 2）

  • NexusInbox の API が OAuth 2.1 の許可を出す（MCP の標準どおり。PKCE、つなぐ先の URL に縛ったトークン）
  • AI のアプリの登録は、MCP の標準の 2 通り（クライアント情報の URL、または動的な登録）に対応する
  • パソコンは届いたトークンを API に問い合わせて確かめる。切ればすぐ使えなくなる
  • 本文の復号はこれまでどおりパソコンだけ

決めてほしいこと

  • 使わない接続を自動で切るまでの日数（案: 30 日）
  • ①の URL の場所: エージェントの「いまの状態」の下（案）
  • ③の場所: エージェント設定の「詳細」の中（案）
