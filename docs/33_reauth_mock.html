③ エージェントを削除する（エージェント → 詳細）

エージェントを削除

「秘書」と、そのパソコンの接続をすべて削除します。元に戻せません。

削除する
World ID で確かめてください 新元に戻せない操作なので、World ID でもう一度確かめます（確かめてから 10 分有効）。
World ID で確かめる
変えること
  • この 3 つの操作は、ログイン (World ID) から 10 分以内でないとサーバが断る（端末の追加・削除と同じ reauthentication_required）。ブラウザを閉じ忘れた・盗まれた古いログインだけでは、読む権限を渡したり、エージェントを消したりできない。
  • 断られたら、その場に案内と「World ID で確かめる」を出す。確かめたあとは元の画面に戻る（②は同じ許可の画面）。もう一度押せば進む。
  • ログインしたばかりなら（初回ガイドの流れなど）何も変わらない。オフにする・許可しないは確かめ直し不要。
