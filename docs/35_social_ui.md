# 35. 画面の作り直し: X の DM 風、スマホとパソコン両方 (2026-11-09)

**画面案**: `docs/35_social_ui_mock.html`
**運営者の判断 (2026-11-09)**: 範囲は「全体の骨格から」、ソーシャル感は「X の DM 風」、端末は「スマホとパソコン両方」。決めてほしいことは推奨どおり。ただし「コンタクト」は呼び名を変えない (「つながり」にしない)。理由: やり取りの用途は広く、関係の薄い相手も多い。「つながり」は合わない

## 1. いまの画面で見つけたこと

- 文字の大きさが 11〜22px の間に 11 種類。決まりがなく、本文と補足の差が分かりにくい
- 書体が英字用の Inter。日本語は端末任せで、英字と日本語の見た目がそろわない
- Gmail の道具 (一括選択、スター、ゴミ箱、ページ送り) が上に並ぶ。エージェントのやり取りでは使わないものが多い
- スマホでは道具の列が横にはみ出し、一覧が右で切れる。下のタブも無い
- 背景の模様と半透明の重なりで、文字の背景が一定でない
- 相手が「誰の」エージェントかが分かりにくい。顔 (アイコン) が無い
- 依頼 (日程調整など) や AI の下書きが、会話の流れの外にある
- 作成画面に「E2E暗号化」「(A2A)」などの言葉が残る。件名が必須に見える
- ログイン画面が暗い宇宙風で英語、文字の明暗差が小さい

## 2. 決めたこと

- **骨格**: パソコンは左にナビ、中央 600px に 1 列、右に「いまの状態」と「あなたの番」。スマホは下にタブ 4 つ (メッセージ / 確認 / エージェント / コンタクト) と右下の「新しい会話」
- **メッセージ**: 相手ごとの会話の一覧 (顔・名前・最後の一言・時刻・未読の点、札で「日程調整」「あなたの確認待ち」「自動で返事しました」)
- **会話**: 吹き出し。依頼はその場のカード (承諾 / 辞退 / 自分で返事)、AI の下書きもその場に出して「この内容で送る」。暗号化と 90 日のことは最初の 1 行だけ
- **エージェント**: 顔と一言を持つ (最初は頭文字と色、あとで画像)。プロフィールと、状態 / 自動返信 / AI / 詳細のタブ
- **件名**: 任意。いまの件名は会話の題として残す
- **ダークモード**: 最初から入れる
- **呼び名**: 「コンタクト」のまま

## 3. デザインの土台

- 文字: 13 / 14 / 15 (本文) / 17 / 20 / 24。13 より小さくしない。太さは 400 と 700 (見出しだけ 800)。行の高さ 1.5
- 書体: 端末の日本語書体 (`-apple-system`, ヒラギノ, Noto Sans JP, Segoe UI, メイリオ)
- 色: 文字 / 補足 / 区切り線 / 主な操作 (自分の吹き出し) / 相手の吹き出し / 動いている / あなたの番 / 止める・消す。ライトとダークで同じ名前の色を入れ替える
- 形: 角の丸み 16、ボタンは丸。影はほぼ使わず線で区切る。背景の模様はやめる。押せるところは 44px 以上
- 人とエージェント: 丸い顔 (持ち主の頭文字と色) と、右下の 🤖。名前は「〇〇さんの (エージェント名)」

## 4. 進め方

1. デザインの土台 (文字・色・形) とナビの骨格を入れ替える
2. メッセージ (会話の一覧) と会話 (吹き出し・依頼カード・下書き)
3. エージェントのプロフィール (顔と一言、API に列を足す)、確認が必要、新しい会話
4. コンタクト、AI の操作履歴、ログイン画面

各段で本番に出す前に、手元で画面を確かめる。

## 5. 送ったメッセージを本人も読めるようにする (2026-11-09、運営者の了承: 「変える」)

これまで本文の鍵は相手の鍵でしか開けないように包んでいたので、送った本人も後から読めなかった (添付だけは本人用にも包んでいた)。DM 風の会話では自分の吹き出しが読めないので、送るときに同じ鍵を自分のエージェントの鍵でも包んで保存する。

- API: `POST /messages` の `envelope.sender_encrypted_key` (任意、`x25519v1:` の形)。暗号文と一緒に保存先の JSON に入れ、`GET /messages/:id/content` で返す。DB の列は増やさない。下書きを送るとき (`POST /agent-drafts/:id/send`) は、確かめたブラウザが鍵を包んで本文に `{ "sender_encrypted_key": … }` を付けられる
- 運営者が読めないことは変わらない (包むのは送り手のエージェントの公開鍵)
- 署名には入れていない。運営者が本人用の包みを差し替えると、本人の画面に別の文が出せてしまう (相手に届く文は署名で守られる)。気になれば、署名の対象に足す (相手側の検証も変える) か、本人の画面で「相手に届いた文」との一致を確かめる
- これより前に送ったものと、パソコンのプログラム (自動返信・パソコンの AI ツール) が送ったものは、まだ本人用の包みが無い。画面には「送ったメッセージ (この端末では中身を表示できません)」と出す。パソコン側はあとで対応する
