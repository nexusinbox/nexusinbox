いまの画面で見つけたこと

  • 文字の大きさが 11〜22px の間に 11 種類。決まりがなく、本文と補足の差が分かりにくい
  • 書体が英字用の Inter。日本語は端末任せで、英字と日本語の見た目がそろわない
  • Gmail の道具（一括選択、スター、ゴミ箱、ページ送り）が上に並ぶ。エージェントのやり取りでは使わないものが多い
  • スマホでは道具の列が横にはみ出し、一覧が右で切れる。下のタブも無い
  • 背景の模様と半透明の重なりで、文字の背景が一定でない（読みにくい）
  • 相手が「誰の」エージェントかが分かりにくい。顔（アイコン）が無い
  • 依頼（日程調整など）や AI の下書きが、会話の流れの外にある
  • 作成画面に「E2E暗号化」「(A2A)」などの言葉が残る。件名が必須に見える
  • ログイン画面が暗い宇宙風で英語、文字の明暗差が小さい

新しい骨格

  • パソコン: 左にナビ（大きめの文字とアイコン）、中央 600px に 1 列、右に「いまの状態」と「あなたの番」
  • スマホ: 下にタブ 4 つ（メッセージ / 確認 / エージェント / コンタクト）、右下に「新しい会話」
  • メッセージ: 相手ごとの会話の一覧（顔・名前・最後の一言・時刻・未読の点）。札で「日程調整」「あなたの確認待ち」「自動で返事しました」
  • 会話: 吹き出しで流れる。依頼はその場でカード（承諾 / 辞退 / 自分で返事）。AI の下書きもその場に出し、「この内容で送る」。暗号化と 90 日のことは最初の 1 行だけ
  • エージェント: プロフィール（顔・名前・一言・アドレス・状態）と、状態 / 自動返信 / AI / 詳細のタブ
  • 新しい会話: 相手をコンタクトと自分のエージェントから選ぶ。件名は任意（あとで「件名を付ける」）

進め方（案）

  1. デザインの土台（文字・色・形）とナビの骨格を入れ替える
  2. メッセージ（会話の一覧）と会話（吹き出し・依頼カード・下書き）
  3. エージェントのプロフィール、確認が必要、新しい会話
  4. コンタクト、AI の操作履歴、ログイン画面

決めてほしいこと

  1. この骨格（左ナビ + 中央 1 列 + 右の欄 / スマホは下タブ）でよいか
  2. エージェントに「顔」と「一言」を持たせるか（推奨: 持たせる。最初は頭文字と色、あとで画像も）
  3. 件名を任意にするか（推奨: 任意。今の件名は会話の題として残す）
  4. ダークモードも最初から入れるか（推奨: 入れる。色を決まりで管理するので手間は小さい）
