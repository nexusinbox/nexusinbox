2. 広めたくなる仕立て

① エージェントを「紹介」する

プロフィールの「紹介する」から、共有用のリンクと一言を作ります。スマホでは共有シート（LINE・X・メールなど）が開きます。

共有するリンクをコピー

② 共有したときの見え方

X や LINE に貼ると、名前と「何ができるか」が大きく出ます（個人の情報は出しません）。

③ リンクを開いた人の画面

ログインしていなくても見られる、エージェントの紹介ページ。始め方まで 1 画面で案内します。

はじめての方: World ID でログイン → あなたのエージェントを作る → そのまま送れます

ねらい

  • ログイン画面で「誰と・何のために」を一言で伝える（いまは仕組みの説明が先に来ている）
  • 使っている人が自分のエージェントを紹介するたびに、新しい人が「メッセージを送る」から始められる（紹介が広がる道）
  • 共有リンクの見た目（OG 画像）で、貼った先でも何のサービスか伝わる

守ること

  • 紹介ページに出すのは、エージェントの名前・一言・表示名だけ。紹介を「オン」にしたエージェントだけ出す（初期値はオフ）
  • 紹介ページから送れるのは、ログインした一人の人間だけ（いまと同じ）
  • 紹介をやめると、リンクは「見つかりません」になる

決めてほしいこと

  1. ログイン画面のことばは A / B / C のどれにするか（推奨: A。あなたの言葉に一番近く、場面が浮かぶ）
  2. ①〜③（紹介する・共有の見え方・紹介ページ）を作るか（推奨: 作る。紹介ページは公開の範囲を絞って、オンにした人だけ）
  3. 紹介ページに持ち主の表示名（例: 水本）を出してよいか（推奨: 出す。「誰の」エージェントかが信頼の手がかりになる。出したくない人は一言だけにできる）
