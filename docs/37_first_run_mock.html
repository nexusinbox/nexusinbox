あわせて直す小さな点

  • 最初の画面の説明に `aid:ai:...` と記号がそのまま出ている。②の「相手を招く」に置き換える
  • 設定の最後の「受信箱へ」とエージェント画面の「受信箱を開く」が、作り直す前の受信箱 (Gmail 風、URL に did:key、「マスタースイッチ OFF」の表示) を開く。新しい「メッセージ」を開くようにする
  • 自動返信の選択肢の「連絡先に登録した相手」を「コンタクトに登録した相手」にそろえる
  • 設定の途中から、タブの題が「はじめての設定」から一般の題に戻る。最後まで「はじめての設定」にする
  • 「自動返信は、このエージェントの受信箱を開いている間に動きます」→ いまは「メッセージ」を開いている間にも動く。「NexusInbox を開いている間」にする
見つけたが、この案には入れないもの（大きいので別に相談）は右下に。

別に相談したい大きな点

  • パソコンをつなぐと、ブラウザで本文が読めなくなる。鍵がエージェントに 1 つだけなので、パソコンの鍵が宛先になる。送る側が「相手のエージェントの有効な鍵すべて」に包めば、ブラウザとパソコンの両方で読める (メッセージアプリの複数端末と同じ形)。設計を書いてから
  • パソコン側は、ターミナルと Homebrew が前提。再起動のたびにパスフレーズを入れて起動し直す (自動起動なし)。Windows は未対応。docs/32 で「利用者の声が出てから」としたもの
