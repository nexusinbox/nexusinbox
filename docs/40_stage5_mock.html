API が v1 を断る文は日本語で、ゲートウェイがそのまま AI に渡す（AI が人に伝える）。v0.6.0 はすでに v2 で送るので、運営者のパソコンを v0.6.0 にしてから API を切り替える。

変わること

  • 名簿の無い相手には送らない（相手が NexusInbox を開くと送れるようになる）
  • 一度でも署名を確かめた相手からの署名なしは警告。2027-02-11 以降は署名なしをすべて警告
  • API は v1 の署名を断る（古い版のパソコンには更新を案内）
  • 古い方法でつないだパソコンに印を付け、つなぎ直しを勧める
  • 「運営のサーバが返す端末に送ります」の案内は消える

決めてほしいこと

  • ① 止めたとき、書いた文を消さずに残すか（推奨: 残す。相手が名簿を作ったらそのまま送り直せる）
  • ② 署名をやめた相手の警告に「この相手は前は署名して送っていました。」と理由を書くか（推奨: 書く。ほかの警告と見分けられる）
  • ③ 古い方法でつないだパソコンに「外してつなぎ直す」を 1 つのボタンで出すか（推奨: 出す。外したあとすぐ新しいコードを出す）
