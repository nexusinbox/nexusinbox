2. 足すブラウザでこれを読み取る

スマホのカメラで読み取るか、足すブラウザでリンクを開いてください。足すブラウザでも、同じ World ID でログインしておきます。

リンクを開けないときは、足すブラウザの「コードを入れる」に:

K7Q2M-9XH4T-8F3J-V6WN-2RCP-ZD4E

あと 9:12 · 待っています…

足すのは、このブラウザが署名できる全部のエージェントです: 秘書、経理

リンクは https://app.nexusinbox.ai/pair#…。# から後ろ（緑の部分）はブラウザがサーバに送らないので、運営のサーバは鍵をすり替えられない。新しいブラウザが鍵を送ってきたら、このブラウザが確かめて自動で名簿に署名する（その場で何も押さなくてよい）。

Chrome (Mac) を外しますか

外すと、このブラウザはメッセージを読めなくなり、読める端末も変えられなくなります。ブラウザのデータを消した・パソコンを手放した・盗まれたときに外してください。

エージェントのアドレスと確認番号は変わりません。相手に「鍵が変わりました」は出ません。新

外すには、World ID でもう一度確かめます。

Chrome (Mac) を外しました。いまは Safari (iPhone) だけが読める端末を変えられます。
どの署名できるブラウザも、ほかの端末を外せる（作ったブラウザも）。外した端末の鍵はサーバがすぐ止めるので、送る側はもう包まない。次の名簿から、外した端末の署名は通らない。署名できるブラウザが 1 つに戻ったら、① の灰色の一言がまた出る。

いまのブラウザが閉じられました
足すブラウザは「待っています」のまま。10 分の間にいまのブラウザで NexusInbox を開けば、そこで確かめて続きます。
すり替えに気づいたときは、自動では名簿に入れない（パソコンの接続コードと同じ）。足すブラウザの画面にも「足せませんでした」と出す。

変わること

  • エージェント画面に「ほかのブラウザを足す」。QR かリンクで、1 回で全部のエージェントに足す
  • 足したブラウザでも、読む・下書きを承認する・名簿に署名する
  • 作ったブラウザを失っても、足したブラウザで外して続けられる。相手に「鍵が変わりました」は出ない
  • 署名できる端末を足す・外すときは、World ID でもう一度確かめる
  • 自動返信を動かすのは 1 つのブラウザだけ（移せる）

決めてほしいこと

  • ② World ID の確認は、「ほかのブラウザを足す」を押した最初に出すか（推奨: 最初。QR を出す前に済ませ、待っている間に何も聞かない。10 分を過ぎたら名簿に署名する前にもう一度聞く）
  • ④ 足す前に届いたメッセージの本文は、一覧に出したまま「このブラウザでは読めません」とするか（推奨: そうする。一覧から消すと、届いていないように見える）
  • ④ 自動返信の切り替えは、エージェント画面の状態タブに置くか（推奨: 置く。どのブラウザで動いているかが端末の一覧と並んで分かる）
