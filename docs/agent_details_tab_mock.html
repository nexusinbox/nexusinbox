変えること
  • 詳細タブの言葉を、開発者向けの言い方（クレデンシャル・keystore・master スイッチ・プロトコル・リビジョンなど）からふつうの言葉にする。英語の画面も同じ考えで直す
  • 使われずに期限が切れた接続コードは一覧に出さない（データとしては残る。サーバ側は変えない）
  • 「失効」は、状態タブの端末と同じ「外す」にそろえる。手で登録する入口と ID のコピーは「開発者向け」の折りたたみに入れる
  • aid と did は「開発者向けの識別子」に折りたたむ。相手に伝えるアドレスは画面の上にあるので、くり返さない
  • 緊急停止の完了メッセージも「クレデンシャル {n} 件、トークン {n} 件」をやめ、「つながっていたパソコンや AI ツールを止めました」にする
決めてほしいこと
  • この方向でよいか（推奨: この方向）
  • 期限切れの接続コードを隠すか（推奨: 隠す。使われていないので、何もする必要がない）
