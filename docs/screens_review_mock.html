2. エージェント画面: パソコンをつなぐ手順が文章の塊で、専門用語が多い

「パスフレーズ」「後半はこのブラウザとパソコンだけが知る部分」「配布ページから入れてください: 配布ページ」、英語のエラー文の引用など。手順と注意が混ざっている。

いま

パソコンのターミナルで、次のコマンドを実行してください。この画面はそのままで大丈夫です。
① はじめての場合は、プログラムを入れます（Mac、Homebrew）:
brew install nexusinbox/tap/nexusinbox
Linux の場合は、配布ページから入れてください: 配布ページ
② つなぎます:
nexusinbox connect H1XQB-9CR36-…
実行すると、パソコンの中の鍵を守るパスフレーズを決めるよう聞かれます。コードは 10 分間、1 回だけ使えます。人には教えないでください。後半はこのブラウザとパソコンだけが知る部分で、運営のサーバには送りません。すでに入れている場合は、先に brew upgrade nexusinbox で最新（v0.5.0 以上）にしてください。古いままだと「A pairing code is 10 letters and digits」と出て、つながりません。

案

パソコンのターミナルで、順に実行します。この画面は開いたままにしてください。
プログラムを入れる（はじめてのときだけ）
brew install nexusinbox/tap/nexusinbox
入れたことがあれば、代わりに brew upgrade nexusinbox
つなぐ
nexusinbox connect H1XQB-9CR36-…
合言葉（パスフレーズ）を決めるよう聞かれます。パソコンの中の鍵を守るためのものです。
この画面に「つながりました」と出たら完了
うまくいかないとき・Linux の場合コードは 10 分で切れます。切れたら「やめる」を押して、もう一度。Linux は 配布ページ から入れます。

このコードは 1 回だけ使えます。人に教えないでください。
